# 语音数据集数据处理与数据增强工具库 (Data Processing & Augmentation)

本仓库包含了用于 VAD (Voice Activity Detection)、ASR (Automatic Speech Recognition) 音频数据预处理、格式转换、降采样、以及深度数据增强（混音、加噪）的纯 Python 工具箱。所有工具已完全解耦 Linux/Kaldi 环境依赖，可在 Windows 系统下开箱即用。

---

## 1. 基础音频格式清洗与切割

### [audio1.py](./audio1.py)
**简介：** 用于对指定目录下的音频文件进行极速的全自动格式净化（原地覆盖或另存为）。
**核心功能：**
* 自动化多通道向单声道（Mono）折叠。
* 提供基于 scipy 的防混叠安全降采样（例如 `48000Hz` 降至 `16000Hz`）。

### [audio_cut.py](./audio_cut.py)
**简介：** `audio1.py` 的重构与二次进阶封装版本。在兼容净化功能的同时，加入了时间轴物理切片能力与丰富的配置参数。
**核心功能：**
* **等距切片（Segmenting）：** 将包含数百小时的长录音按预设时长（如 `15秒`）物理分割为数千个小片段，天然适应深度学习模型定长输入需求。
* **动态配置：** 一键开启/关闭单声道转换、重采样能力；
* **导出留档：** 支持源目录一键迁移备份至全新目录，并**完全保留原始内部层级菜单树（子目录）结构**，极大简化管理。

## 2. 核心数据增强 (Audio SNR / Noise Augmentation)

在这部分，我们将背景噪声（长时平稳底噪）或前景噪声（短时瞬态异音）混合到干净语音中，通过精准控制 SNR (信噪比) 大幅提升机器学习模型的抗噪泛化能力。

### [SNR_audio.py](./SNR_audio.py)
**简介：** 最早的纯 Python 重写的噪声叠加脚本之一，用来代替原本厚重的 Linux Kaldi Bash 流程。
**特点：**
* 通过防静音能量检测算法 (`active_speech_power`) 精确计算纯净语音发音段 SNR。
* 支持多层次信噪混合运算。拥有破音抑制（波峰削顶限制）保护机制。

### [audio_SNR.py](./audio_SNR.py)
**简介：** 在 `SNR_audio.py` 的基础上加入了更深度的混合层——即**支持叠加前景噪声（Foreground Noise）**。
**使用场景：**
* **前景噪+背景噪复合画布：** 对于诸如 IoT 唤醒设备或者抗噪录音笔来说，除了抵抗风扇/空调音（背景噪）外，还需要抵抗由于突然的咳嗽声、摔门声、狗叫声（前景噪）导致的误检。本脚本通过建立时序“复合画布”，能在稳定的背景噪音基础上，每隔 n 秒点阵式穿插突发噪声。高度仿真真实嘈杂工作物理场。

### [augment_multi_snr_background.py](./augment_multi_snr_background.py) 
*(由 `SNR_audio copy.py` 重命名升级而来)*
**简介：** **控制变量对照实验**专用型多尺度信噪比加噪工具。
**使用场景与机制原理：**
* 它是数据评估与测试集生成的最强者。对于某一条纯净语音，它不会只生成 1 个增噪音频。我们抛弃了全随机性导致由于声源不同带来的不可控误差。
* 脚本一旦随机抽中某首特定的噪声，就会对该纯净语音**锁死同一背景源、锁死相同截取起播点**，分别以不同的音压强度（如 `[5dB, 8dB, 10dB, 15dB]`）混合。
* 自动创建 `5dB/`、`8dB/`、`10dB/`、`15dB/` 这四个互为严格对照的测试集目录，方便我们在测试模型时画出漂亮的 `SNR - Accuracy` 性能衰减鲁棒性曲线。它的 `csv` 甚至能顺藤摸瓜找到这首歌的相对源路径。

## 🔧 上手使用总结 (Workflow)

对于一般的开发者，推荐的工作流为：
1. 先利用 **`audio_cut.py`** 遍历搜刮各种格式混乱的前端数据集（或者是网上找的杂乱噪声集），做预处理：提取 16kHz的单声道并按 15s 标准切段。作为我们的标准 `Clean_Source` 与 `Noise_Source`。
2. 若是要训练一个能对抗突发爆破音的模型，使用 **`audio_SNR.py`** 把前景+环境音混合进去生成训练集 (`Train_Set`)。
3. 若是要做严格的对抗性能指标评估与绘制曲线，执行 **`augment_multi_snr_background.py`**，批量生成多难度阶级测试数据集 (`Test_Sets`)。
